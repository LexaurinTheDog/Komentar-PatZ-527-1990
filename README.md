# Komentář k zákonu č. 527/1990 Sb., o vynálezech a zlepšovacích návrzích

Otevřený komentář k patentovému zákonu (PatZ) — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; patentovatelnost, právo na patent a zaměstnanecké vynálezy, účinky patentu, licence, řízení před Úřadem průmyslového vlastnictví, evropský patent, dodatková ochranná osvědčení a zlepšovací návrhy.

Konsolidované znění: dokument e-Sbírky `SB-1990-00527_2022-02-01`.
